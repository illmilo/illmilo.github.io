### Суть задания

> **Операнд** -- это объект, над которым **совершается операция** (например, сложение).
{: .prompt-info }

Дается арифметическое выражение, записанное в системе счисления. В операндах есть неизвестная цифра $x$. Результат выражения должен быть кратен $b - 1$, где $b$ -- основание системы счисления операндов.

**Нужно:**

1. Определить $x$;
2. Рассчитать итоговое значение выражения;
3. Найти частное от деления результата на `b - 1`.

> Операнды арифметического выражения записаны в системе счисления с основанием $19$:
> 
> $$123x24_{19} + 4x592_{19}$$
> 
> В записи чисел переменной $x$ означена неизвестная цифра из разрешенного набора системы счисления с основанием $19$. Определите **наименьшее** значение $x$, при котором значение данного арифметического выражения кратно $18$. 
>
> Для найденного $x$ вычислите **частное от деления значения арифметического выражения на $18$** и запишите его в ответе в десятичной системе счисления.

### Делимость на $b - 1$

Обратите внимание на числа в условии: основание системы счисления $b = 19$, а делить нас просят на $18$, то есть на $b - 1$. Это -- главная лазейка задачи.

> Чтобы число, записанное в системе счисления с основанием $b$, делилось на $b-1$, **сумма его цифр должна быть кратна $b-1$**.
{: .prompt-info }

Ничего не напоминает? Это точь-в-точь признак делимости на $9$ в нашей привычной десятичной системе счисления. Чтобы число делилось на $9$, сумма его цифр должна делиться на $9$.

**Докажем** этот признак делимости:

Возьмем для примера $(n+1)$-значное число $(a_{n} ... a_1 a_0)_b$, где $a_i$ -- это **цифра** $b$-ричной системы счисления, и **переведем** в десятичную систему счисления:

$$(a_{n} ... a_2 a_1 a_0)_b = (a_n \cdot b^n + ... + a_2 \cdot b^2 + a_1 \cdot b^1 + a_0 \cdot b^0)_{10}$$

Представим $b = ((b - 1) + 1)$:

$$(a_n ... a_1 a_0)_b = a_{n} \cdot ((b-1) + 1)^{n} + ...$$

Вспомним формулы квадрата и куба суммы:

$$
(c+d)^2=c^2+2cd+d^2\\
(c+d)^3=c^3+3c^2d+3cd^2+d^3
$$

> При любом натуральном $n$ в формуле $(c+d)^n$ при **раскрытии скобок** во всех слагаемых, **кроме последнего** ($d^n$), будет множитель $c$.
>
> Значит, множитель $c$ можно **вынести за скобки**.
>
> Следовательно, все **слагаемые, кроме последнего**, будут **кратны $c$**.
{: .prompt-info }

Перенесем это на наш случай $c=b-1$:

$$(a_{n} ... a_2 a_1 a_0)_b = (a_n \cdot (c + 1)^n + ... + a_2 \cdot (c+1)^2 + a_1 \cdot (c+1) + a_0)_{10}$$

Вынесем общий множитель $c$, который появится при раскрытии $(c+d)^n$, за скобки:

$$a_n\cdot(c\cdot(...) + 1^n) + ... + a_2 \cdot (c\cdot(...)+1)^2 + a_1 \cdot (c+1) + a_0$$

Раскроем скобки:

$$a_n\cdot c \cdot (...) + a_n\cdot 1^n + ... +a_2\cdot c \cdot (...) + a_2\cdot 1^2 + a_1\cdot c + a_1\cdot 1 + a_0$$

И вынесем $c$ за скобки для общих слагаемых:

$$
c\cdot(a_n \cdot (...) + ... + a_2\cdot (...) + a_1) + a_n\cdot 1^n + ... + a_2\cdot 1^2 + a_1 \cdot 1 + a_0
$$

А теперь вернем $b-1$ и избавимся от умножения на $1$:

$$
(b-1)\cdot(...) + a_n + ... + a_2 + a_1 + a_0
$$

**Вывод:**

Поскольку первая часть выражения -- это произведение $(b-1)$ с каким-то числом, то вся первая часть кратна $b-1$. Следовательно, если сумма из второй части $a_n + ... + a_2 + a_1 + a_0$ будет кратна $b-1$, то все выражение в $10$-ной системе будет кратно $b-1$.

### Поиск $x$

Хорошо, мы поняли, что нам нужно найти значение арифметического выражения в $b$-ричной системе счисления, не зная $x$, а потом найти сумму цифр выражения.

Но как составить **итоговое уравнение**, чтобы найти $x$?

Начнем с определения **диапазона** значения.

Переменная $x$ -- это обычная **цифра** в $b$-ричной системе счисления. Следовательно, ее числовое значение будет находиться в **пределах числовых значений цифр** $b$-ричной системы счисления:

$$0\leq x\leq b-1$$

Если сложить все известные цифры из нашего примера:
* Сумма цифр первого операнда: $$1 + 2 + 3 + x + 2 + 4 = 12 + x$$
* Сумма цифр второго операнда: $$4 + x + 5 + 9 + 2 = 20 + x$$
* Общая сумма цифр выражения: $$(12 + x) + (20 + x) = 32 + 2x$$

Нам нужно, чтобы выражение $32 + 2x$ делилось на $18$. Скажем, что $m$ -- это натуральное число, множитель. Тогда:
$$32+2x=18m$$

Осталось подставить $m$ и решить уравнение.

1. **Наименьший** $x$: 
    Подставляем по очереди $m = 0, 1, 2$. При $m = 0, 1$ у нас $x < 0$, что **не подходит по диапазону значений** $x$. > При $m = 2$ получаем $32 + 2x = 36$. Значит, наименьший $x = 2$.
2. **Наибольший** $x$: 
    Ищем дальше. При $m = 3$ получаем $32 + 2x = 54 \Rightarrow 2x = 22 \Rightarrow x = 11$. Цифра $11$ входит в $19$-ричную систему. Проверяем дальше: $32 + 2x = 72 \Rightarrow 2x = 40 \Rightarrow x = 20$ (уже перелет, цифры $20$ в системе нет). Значит, наибольший $x = 11$.

> $x$ является **натуральным числом** ($x \in N$). Если при поиске у вас получился **нецелый** $x$, значит, такое значение **не подойдет**.
>
> Если значение $x$ **не входит в диапазон** числовых значений цифр $b$-ричной системы счисления, то такое значение **не подойдет**.
{: .prompt-warning }

### Программное решение

Напишем код, который сделает всё за нас. 

Я продемонстрирую два способа решения:

1. Через встроенную функцию `int(строка, основание)` -- требуется знание английского алфавита;
2. Ручным способом через **сумму цифр, умноженных на $b^r$**, где $r$ -- индекс разряда множимой цифры.

> Помните, что значения цифр $x>9$ записываются **в виде букв**.
>
> Если вы плохо знаете английский алфавит, **его необходимо выучить**, либо же используйте **второй способ**.
{: .prompt-tip }

Для начала подберем значение $x$. Будем перебирать все значения $b$-ричной системы счисления, в нашем случае $b=19$.

1. Перебираем все возможные значения $x$, в т.ч. буквенные:
    ```python
    for x in '0123456789ABCDEFGHI':
    ```

2. Перебираем **числовые** значения $x$ (без букв):
    ```python
    for x in range(19):
    ```

Переведем все операнды в $10$-ную систему счисления:

1. Используем команду `int(b-ричное, b)` для перевода $b$-ричного числа в десятичное:
    ```python
        op1 = int(f'123{x}24', 19)
        op2 = int(f'4{x}592', 19)
    ```
2. Вручную прописываем сложение всех цифр, помноженных на $b^r$, где $b$ -- основание системы счисления, а $r$ -- номер разряда цифры:
    ```python
        op1 = 1*19**5+2*19**4+3*19**3+x*19**2+2*19+4
        op1 = 4*19**4+x*19**3+5*19**2+9*19+2
    ```

Запишем арифметическое выражение:

```python
    ar = op1 + op2
```

Пропишем условие выражения -- кратность $b-1=18$:

```python
    if ar % 18 == 0:
        print(x, ar / 18)   # выводим значение $x$ и частное отделение (проверьте на целочисленность!)
```

**Шаблон программы с алфавитом**:

```python
b = _   # прописать систему счисления
for x in '':    # прописать все цифры (и буквы) b-ричной системы
    op1 = int(f'', b)   # прописать первый операнд. x прописать как {x}
    ... # прописать другие операнды точно так же
    ar = _  # используя переменные операндов, созданные выше, прописать само арифметическое выражение
    if ar % (b - 1) == 0:
        print(x, ar / (b - 1))
```

**Шаблон программы без алфавита**:
```python
b = _   # система счисл
for x in range(b):
    op1 = _ # сумма цифр операнда, помноженная на основание в степени индекса разряда
    ... # прописать другие операнды
    ar = op1 + + _  # прописать сумму всех операндов
```

### Суть задания

В задании обязательно даются операнды вида $b^n_{10}$, которые нужно записать в $b$-ричной системе счисления.

**Нужно**:
1. Определить вид $b$-ричной записи операндов;
2. Изменить цифры $x_b$, подогнав по условию задания;
3. Перевести полученное число $x_{new}$ в $10$-ную систему счисления.

> Значение арифметического выражения $3^{100} - x$, где $х$ — целое положительное число, **не превышающее** $2030$, записали в **троичной** системе счисления. Определите **наибольшее** значение $x$, при котором в **троичной** записи числа, являющегося значением данного арифметического выражения, содержится **ровно пять нулей**.
> 
> В ответе запишите число в десятичной системе счисления.

### Степень основания

В глаза бросаются операнды вида $b^n_{10}$.

Возьмем в пример привычные десятичные числа и посмотрим на закономерность:

$$
10^6_{10} = 1 000 000_{10}\\
10^3_{10} = 1 000_{10}
$$

Видим закономерность: во всех случаях $10^n$ у нас одна `1` и $n$ `0`.
Проверим это в недесятичных системах системах счисления:

$$
3^3_{10} = 1000_3\\
5^2_{10} = 100_5
$$

*Пояснение*: как видите, нули появляются из-за того, что $b^n$ **на всех этапах делится на $b$**, пока не дойдет дойдет до $b^0 = 1$.

![](/assets/img/14(2).png)

> $b_{10}^n = 10...0_b$, где $1$ в разряде $n$.

### Поиск $x$

В задании нам также дается **верхний** или **нижний** предел значения $x$. Такое число нужно перевести в $b$-ричную систему счисления, чтобы понять, в каком диапазоне мы подбираем число.

В нашем задании $x_{10} \leq 2030_{10}, b = 3$. 

Можно перевести вручную через деление или программой (см. [статью про перевод]({% post_url 2026-09-02-intro %}#перевод-из-10-ной)).

$$
2030_{10} = 2210012_3
$$

Значит, $3^{100} - x$ в $b$-ричной системе:

![](/assets/img/14(3).png)

_Пояснение_: $2$ над цифрами -- это займ единицы у **следующего разряда** $+ b$ в связи с займом к текущему разряду.

> Поскольку в этом задании `0` в $b$-ричной системе счисления идут **подряд**, мы можем смело прибавить $b-1$ ко всем идущим подряд нулям справа-налево **помимо нулевого разряда** -- к нему добавляем $b$.
>
> При этом не забудьте в **первом попавшемся ненулевом разряде слева** от последовательности нулей просто вычесть `1`. 
{: .prompt-tip }

Как видим, в результате вычислений у нас два `0` вместо `5` по условию. Обратим внимание, что `0` появляются там, где мы вычитаем $b-1 = 2$ из разряда сверху. Следовательно, нам нужно добавить еще три разряда $b-1$ в $x_3$, **исключая нулевой разряд** (в нем 0 можно получить только при вычитании `0`).

Поскольку нас просят найти **наибольшее значение** $x_{10} \leq 2030_{10} \Rightarrow x_3 \leq 2210012_3$, нам нужно понять, что если мы просто **заменим** $3$ разряда $x_3$ на $2$, то мы получим $x_3 > 2210012_3$, ведь **увеличение разрядов в числе ведет к увеличению всего числа**.

Значит, мы можем **компенсировать** -- уменьшить какой(-ие)-то разряд(-ы) и увеличить три других до значения $2$.

Что, если **уменьшить самые незначительные разряды** -- те, что справа? Ведь тогда число уменьшится меньше всего. Давайте посмотрим, что произойдет:

![](/assets/img/14(4).png)

_Примечание_: в случаях 3, 4 число **больше** $2030_{30}$, а в случаях 1 и 2 количество нулей не соответствует критерию задания.

> Если нужно **увеличить разряды вычитаемого**, при этом **не превышая начальное число**, нужно **уменьшить разряд слева** и **увеличить необходимые разряды справа от увеличенного**.
>
> Если нужно **уменьшить разряды вычитаемого**, при этом **не уменьшая начальное число**, нужно **увеличить разряд слева** и **уменьшить необходимые разряды справа от уменьшенного**.
{: .prompt-tip }

В нашем случае новый $x$ должен **не превышать начальный**. Воспользуемся логикой **компенсации** -- **уменьшим** разряд **слева** чтобы **увеличить** разряды **справа от уменьшенного**:

![](/assets/img/14(5).png)

### Программное решение

Решение программой делится на 2 этапа:

* Написание функции подсчета **необходимых цифр** (критерий из задания) в системе счисления;
* Подбор правильного значения $x$ методом **брутфорса** (перебора).

#### Этап 1: Функция подсчета цифр

Возьмем функцию перевода числа из $10$-ной системы из [введения]({% post_url 2026-09-02-intro %}#перевод-из-10-ной):

```python
def to_b(n, b):
    s = ""
    while n:
        s = str(n % b) + s
        n //= b
    return s
```

Такая функция вернет число в $b$-ричной системе счисления. Однако нас не интересует вид самого числа в $b$-ричной системе счисления, нас интересует только **количество нулей**. Модифицируем функцию:

```python
def cnt0(n, b):
    k = 0   # счетчик 0
    while n:
        if n % b == 0:  # если 0 в b-ричке
            k += 1      # увеличитть счетчик 
        n //= b
    return k    # фукнция возвращает кол-во нулей числа n в b-ричке
```

#### Этап 2: Подбор $x$

Функция окончена. Дальше грамотно подберем $x$. 

```python
# ищем наибольшее значение => идем от большего к меньшему
for x in range(2030, 1, -1): # диапазон из задания
```

Пропишем условие для $x$ -- количество нулей в результате работы функции `=5`. 

В качестве аргумента $n$ возьмем **арфиметическое выражение** из задания, а аргумент $b = 3$ (троичная система счисления).

```python
    if cnt0(3**100 - x, 3) == 5:    # если ф-ия насчитает ровно 5 нулей
        print(x)                    # x подходит 
        break                       # самый первый x -- наибольший (идем от большего к меньшему)
```

**Итоговый шаблон программы**:
```python
def cnt(n, b):
    k = 0
    while n:
        if n % b _: # прописать критерий цифр
            k += 1
        n //= b
    return k

# наибольший - идем от большего к меньшему с шагом -1
# наименьший - идем от меньшего к большему с шагом 1
for x in range(_, _, _): # взять диапазон из задания 
    # 
    if cnt(_ - x, _) _: # вписать выражение, систему счисления, критерий счетчика цифр
        print(x)
        break
```

**Шаблон критерия на максимальное/минимальное количество цифр**:
```python
def cnt(n, b):
    k = 0
    while n:
        if n % b _: # прописать критерий(-ии) цифр
            k += 1
        n //= b
    return k

# первичным for записываем все количества цифр при разных значениях x
m = _([cnt(_ - x, _) for x in range(_, _, _)]) # используйте max() или min()

for x in range(_, _, _):
    if cnt(_ - x, _) == m:
        print(x)
        break
```

## Степени без $x$ 

Это задание **редко** встречается на реальном экзамене, но **часто** встречается на пробниках. Суть у него такая же, как у задания с $x$, вот только больше арифметических действий: нужно разделить по двум группам **вычитаемые** и **слагаемые**, а также привести все операнды к виду $b^n$.

Здесь от ученика ожидают умение **приводить операнды** к виду $b^n$, **складывать**, **вычитать** и **умножать** 

### Суть задания

Главная идея -- **разбить слагаемые и вычитаемые** на две скобки.

> _Досрочная волна 2026_
>
> Значение арифметического выражения
>
> $$2\cdot 2187^{567} + 729^{566} - 2\cdot 243^{565} + 81^{564} - 2\cdot 27^{563} - 6561$$
>
> записали в системе счисления с основанием $27$. Определите в $27$-ричной записи числа количество цифр с **чётным** числовым значением, **превышающим $9$**.

### Аналитическое решение

Сначала разобьем **слагаемые** и **вычитаемые** на 2 группы:

$$
(2\cdot 2187^{567} + 729^{566} + 81^{564}) - (2\cdot 243^{565} + 2\cdot 27^{563} + 6561)
$$

> $$(a^n)^m = a^{n\cdot m}$$
>
> $$\frac{a^n}{a^m} = a^{n - m}$$
>
> $$a^n \cdot a^m = a^{n + m}$$
{: .prompt-info }

#### Этап 1: Первая скобка

Решим первую скобку. Выразим каждый операнд в виде степени $b^n$.

Берем в учет $27=3^3 \Rightarrow 3 = 27^{\frac{1}{3}}$. Дальше будем искать каждый операнд в виде $3^n\Rightarrow (27^{\frac{1}{3}})^n$, поскольку не все операнды выражаются в виде полной степени $27^n$.

**Итого**:

$$
2\cdot (27^{\frac{7}{3}})^{567} + (27^2)^{566} + (27^{\frac{4}{3}})^{564}\\
= 2\cdot 27^{\frac{3 969}{3}} + 27^{1132} + 27^{\frac{2256}{3}}\\
= 2\cdot 27^{1323} + 27^{1132} + 27^{752}
$$

**Итого в $27$-ричном виде**:

![](/assets/img/14(6).png)

#### Этап 2: Вторая скобка

Решим вторую скобку. Выразим каждый операнд в виде $b^n$:

$$
2\cdot (27^{\frac{5}{3}})^{565} + 2\cdot 27^{563} + 27^{\frac{8}{3}}\\
=2\cdot (27^{\frac{2825}{3}} + 27^{563}) + 27^{\frac{8}{3}}
$$

В этой скобке появились **дробные степени**.

Разберемся, какой вид будут иметь числа с дробной степенью:

![](/assets/img/14(7).png)

> При дробной степени в разряде **целой части дроби** находится цифра, равная **основанию, возведенному в нецелую часть степени**.
{: .prompt-info }

$$
\frac{2825}{3} = 941\frac{2}{3}\\
\frac{8}{3} = 2\frac{2}{3}\\
\frac{5}{3} = 1\frac{2}{3}
$$

Итак, у всех трех дробей одинаковая нецелая часть -- $\frac{2}{3}$. Из примера выше мы видели, что при такой нецелой части в разряд **целой части** встанет цифра $9$.

**Итоговый вид всего числа**:

#### Этап 4: Вычисление количества цифр по индексам

Вот и все! Зная опорные индексы, мы можем вычислить, сколько четных цифр $>9$ будет между этими индексами, используя формулы на количество чисел различных интервалов. Вы можете самостоятельно доказать эти свойства или выводить их, используя маленькие примеры. Например вычислите, сколько индексов занимают нули в записи $9991000199$, зная:

* Индекс разряда обеих единиц (**открытый интервал**, индексы единиц не включаются в ответ);
* Индекс разряда первой единицы и последнего нуля (**полузакрытый интервал**, индекс единицы не включается, а последнего нуля -- включается);
* Индекс разряда первого нуля и последнего нуля (**закрытый интервал**, индексы нулей включаются).

Интервал|Количество чисел
-|-
**Полузакрытый** $[a; b)$ или $(a; b]$|$b - a$
**Закрытый** $[a; b]$|$b - a + 1$
**Открытый** $(a; b)$|$b - a - 1$

В нашем случае четные цифры $>9$ берут такие индексы: $(1132; 941)$, $(725; 2]$.

**Ответ**:

$$
(1132-941-1)+(752-2)=940
$$

### Программное решение

По сути, мы используем тот же шаблон, что и в [программном решении задания на степени с $x$](#программное-решение-1), только здесь не нужно перебирать $x$.

**Шаблон программы:**

```python
def cnt(n, b):
    k = 0
    while n:
        if n % b _: # указать критерий(-ии) цифры из задания
            k += 1
        n //= b
    return k

print(cnt(_))   # прописать арифметическое выражение из задания
```
