Алгоритмы -- это **основа программирования**. В этом посте вы сделаете свои первые шаги в программировании на Python, научитесь писать свои первые алгоритмы с использованием модуля рисования Turtle. Заодно вы сразу получите необходимую базу для решения одного задания на экзамене -- №6!

## Основные понятия

| Термин | Определение |
|---------|------------|
| **Алгоритм** | Последовательность **команд** для решения определенной задачи |
| **Команда** | Действие, которое выполняет **исполнитель** |
| **Исполнитель** | Объект, выполняющий команды |

**Синтаксис** команд в Python:

```python
название_комманды()
```

**Абстрактно** опишем алгоритм приготовления бутерброда с джемом:

1. Отрезать кусок хлеба;
2. Открыть банку с джемом;
3. Зачерпнуть ножом джем;
4. Размазать джем по куску хлеба.

Алгоритмы пишутся на определенном уровне **абстракции** (обобщения). Например, мы с вами не будем указывать программе, как ей переключать транзисторы или использовать адреса памяти в компьютере. Мы считаем, что для Python это **само собой разумеющееся** -- так и есть.
 
Так и в примере выше: мы пропускаем шаги "взять хлеб", "взять нож" и другие, потому что считаем это **очевидным**. Это и есть **абстракция**.

## Исполнитель Черепашка

В Python исполнителями выступают **модули стандартной библиотеки Python**. Сегодня мы познакомимся с модулем `turtle`, позволяющим **рисовать кодом**.

Черепашка (`turtle`) рисует **хвостом** -- это ее **перо**. Рисует она в **декартовой системе координат**.

Термин|Определение|Пояснение
-|-|-
Стандартная библиотека Python|Набор готовых **модулей**| Словно полка с огромным количеством книг
Модуль|Файл с кодом на Python (`.py`) с готовыми **командами**, которые вы можете использовать|Как книга по физике, из которой можно взять формулу, не зная, как ее вывести

Для того, чтобы использовать исполнителя (а вернее его команды), его нужно подключить к вашему файлу Python.

Для этого мы буквально **импортируем все команды из модуля**:

```python
from turtle import *
# дословно: из черепашки импортировать все команды
```

> Состояние Черепашки **по умолчанию**:
> 
> - **Опущен**
> - **Черный** цвет пера
> - **Толщина** линий -- $1$ пиксель
> - Смотрит вдоль **положительной оси** $x$
{: .prompt-info }

| Команда       | Что делает |
| ------------- | ------------------------------------------------------------------------------------ |
| `forward(n)`  | Вперёд на `n` пикселей                                                               |
| `backward(n)` | Назад на `n` пикселей                                                                |
| `left(a)`     | Поворот влево на `a`°                                                                |
| `right(a)`    | Поворот вправо на `a`°                                                               |
| `goto(x, y)`  | Перейти в координату `x, y` |
| `speed(n)`    | Установить скорость движения (число от `1` до `10`, где `10` - максимальная скорость)|
| `tracer(0)`   | Отключить обновление экрана (анимацию рисования)                                     |
| `done()`      | Закончить рисование                                                                  |
| `penup()`          | Поднять перо                                   |
| `pendown()`        | Опустить перо                                  |
| `color("color")`   | Изменить цвет пера на `color`                  |
| `dot(20, "color")` | Нарисовать точку диаметром `d` и цвета `color` |

## Цикл алгоритма

Во многих алгоритмах потребуется **повторять одно и то же действие несколько раз**.

Вместо того, чтобы копировать и вставлять команды, **нагромождая код**, давайте научимся пользоваться счётным (считает количество повторений) циклом `for`.

> **Цикл** -- это **многократное повторение** заданного алгоритма.
>
> Цикл `for` -- это счетный цикл, который позволяет повторить алгоритм **определенное количество раз**.
>
> Благодаря **отсутпам** можно создать **блок кода**, тем самым обозначив **алгорим, который должен повторяться**.
{: .prompt-info }

Для того, чтобы удобно записать повторяющиеся несколько раз действия, можно использовать цикл `for` (для). Благодаря счетчику мы сможем сосчитать, сколько раз был повторен алгоритм, и вовремя остановиться. На следующих занятиях мы разберем этот цикл подробнее.

**Синтаксис** цикла `for`:

```python
for repetition in range(n): # дословно: для повторения в диапазоне n раз
```
