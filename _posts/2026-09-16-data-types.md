Как заставить программу запоминать информацию? Как объяснить ей, что 2 + 2 = 4, а не 22? Когда нужно ставить кавычки в программе, а когда -- нет? В этом посте вы узнаете, что такое **переменные** и какие **типы данных** они принимают.


## Переменные

> **Переменная** -- это **именованная область памяти** компьютера, предназначенная для **хранения** данных.
{: .prompt-info }

![](/assets/img/data-types(1).png)
_Визуализация хранения переменных в памяти компьютера_

В общем, переменную мы создаем тогда, когда нужно **запомнить** какое-то значение.

У переменной есть:

- **Имя**, чтобы к ней обращаться;
- **Значение**, чтобы в ней что-то хранить.

При создании названия переменной можно использовать:

- буквы (русские и латинские)
- цифры
- нижнее подчёркивание `_`

> Нельзя **начинать** название переменной **с цифры**!
>
> Нельзя использовать в названии переменных **пробелы** или любые другие **посторонние знаки/символы** кроме тех, что перечислены выше!
{: .prompt-danger }

Примеры создания переменных:

```python
name = "Миша"
age = 14
pi = 3.14
x, y, z = 1, 2, 3   # В результате: x = 1, y = 2, z = 3
a = b = c = 0       # В результате: a = 0, b = 0, c = 0
a, b = b, a         # В результате обмен значениями: a = b, b = a
```

## Типы данных

> **Типы данных** разделяют информацию на разновидности и объясняют, как **оперировать** этой информацией (складывать, вычитать и пр.).
{: .prompt-info }

| Тип        | Что хранит          | Пример значения |
| ---------- | ------------------- | ---------- |
| `int`      | Целые числа         | `5`        |
| `float`    | Дробные числа       | `3.14`     |
| `str`      | Текст               | `"Привет"` |
| `bool`     | Истина или ложь     | `True`     |

### Приведение типов

Иногда нужно **преобразовать** один тип данных в другой.

В таком случае нужно использовать **имена типов данных**, как **команды**:

| Команда    | Результат        |
| ---------- | ---------------- |
| `int(x)`   | Преобразует `x` в целое число    |
| `float(x)` | Преобразует `x` в дробное число  |
| `str(x)`   | Преобразует `x` в строку         |
| `bool(x)`  | Преобразует `x` в логический тип |

Пример применения команд:

```python
s = "101"   # тип s: str ("101")
n = int(s)  # тип n: int (101)
s2 = str(n) # тип s2: str ("101")
```

## Исполнитель Консоль

> Консоль -- это простейший **исполнитель**, встроенный в Python "из коробки", который позволяет общаться с программой через **ввод/ вывод данных**.
{: .prompt-info }

| Команда            | Действие                                |
| ------------------ | --------------------------------------- |
| `input(подсказка)` | Запрашивает ввод в консоли в виде `str` |
| `print(данные)`    | Выводит данные в консоль                |

> `input()` всегда принимает ввод в **строчном типе** (`str`).
>
> Практически всегда результат команды `input()` нужно сохранить в переменную, чтобы запомнить ввод пользователя.
{: .prompt-warning }

Пример команд:
```python
age = int(input("Введите свой возраст: "))
print("Привет!")
```

> В подсказке команды `input()` лучше ставить пробел в конце (перед закрывающей кавычкой), чтобы **разделить** подсказку и ввод пользователя.
{: .prompt-tip }

### Вывод переменных

Просто вывести значение одной переменной нетрудно:

```python
print(name) # выведет: Миша
```

Но что делать, если мы хотим вывести несколько значений, в том числе несколько переменных? Для этого есть несколько способов. Давайте разбираться.

#### Способ 1. Через запятую

```python
print("Меня зовут", name)
```

#### Способ 2. Через сложение строк

```python
print("Меня зовут " + name)
```

> Складывать можно только `str` + `str`! Придется использовать команду преобразования `str(числовая_переменная)`, чтобы сложить строку и числовую переменную.
{: .prompt-danger }

#### Способ 3. Через форматированные строки (f-строки)

Самый удобный вариант.

```python
print(f"Меня зовут {name}")
```

---

Результат всех 3 способов одинаковый:

```text
Меня зовут Миша
```

## Арифметические операторы

> **Арифметические операторы** выполняют математические действия (сложение, вычитание и пр.).
>
> **Операнд** -- это объект, над которым совершается операция. В случае с арифметическими операторами, операнды -- это числа, которые мы складываем.
{: .prompt-info }

В выражении:

```python
a + 5
```

- `+` -- оператор
- `a` и `5` -- операнды

Вот арифметические операторы в соответствии с их приоритетами.

* Чем меньше цифра приоритета, тем выше приоритет (1 -- самый высокий приоритет);
* Действия с одинаковым приоритетом выполняются по порядку справа-налево.

| Оператор | Действие              | Пример   | Приоритет
| -------- | --------------------- | -------- |
| `()`|Выполнить в первую очередь|a * (b + c) | 1
| `**`     | Возведение в степень  | `a ** b` | 2
| `*`      | Умножение             | `a * b`  | 3
| `/`      | Деление               | `a / b`  | 3
| `//`     | Целочисленное деление | `a // b` | 3
| `%`      | Остаток от деления    | `a % b`  | 3
| `+`      | Сложение              | `a + b`  | 4
| `-`      | Вычитание             | `a - b`  | 4

## Срез числа

Для того, чтобы взять у числа какую-то его часть (буквально **отрезать** от остальной части числа), вспомним, как при помощи арифметических операторов мы можем сдвинуть точку, отделяющую целую часть числа от нецелой, тем самым разбив число на две части:

$$
1234.0 \rightarrow 123.4
$$

Многие вспомнят школьную программу и тот факт, что такого результата мы можем добиться, если поделим число на $10^x$, причем $x$ -- это на сколько цифр влево сдвинется точка.

Здесь получится, что целая часть $= 123$, остаток от деления (дробная часть) $= 4$. Именно благодаря взятию целой части или остатка от деления вы сможете сказать, какую часть числа, **разделенного точкой**, вы хотите взять -- ту, что слева от точки, или ту, что справа.

| Действие     | Значение                                                |
| ------------ | ------------------------------------------------------- |
| `n // 10**x` | Взять часть слева от разделительной точки  |
| `n % 10**x`  | Взять часть справа от разделительной точки |

Например, так можно разбить число на разряды:

```python
num = 123
units = num % 10**1             # взять цифру справа от точки
tens = (num // 10**1) % 10**1   # взять цифры слева от точки, потом у них же взять цифру справа от точки
hundreds = num // 10**2         # взять цифру слева от точки
```
