Логические выражения позволят вам управлять своей программой в зависимости от обстоятельств -- так называемых **условий**. В этом посте мы разберем, как составлять логические выражения в Python.

## Логические выражения

> **Логические выражения** -- это выражения, значения которых возвращают булево (**логическое**) значение: `True` (истина) или `False` (ложь).
{: .prompt-info } 

В Python для создания таких выражений используются операторы сравнения, которые имеют одинаковый приоритет и выполняются слева направо:

* `>` (больше)
* `<` (меньше)
* `>=` (больше или равно)
* `<=` (меньше или равно)
* `==` (равно)
* `!=` (не равно)

Пример простейшего логического выражения:

```python
print(10 > 5)  # Выведет: True
```

## Сложные логические выражения

Сложные логические выражения -- это объединение нескольких простых условий.

Для объединения используются операторы:

* **`and` (И)**: возвращает `True`, только если **оба** операнда истинны.
* **`or` (ИЛИ)**: возвращает `True`, если хотя бы **один** из операндов истинен.

А также есть один **унарный оператор**, который также является логическим, но работает он, в отличие от предыдущих, только с **одним операндом**: 

* **`not` (НЕ)**: инвертирует (переворачивает) логическое значение (превращает `True` в `False` и наоборот).

> В Python логические операторы поддерживают так называемое **ленивое вычисление**. Например, в выражении `A and B`, если `A` ложно (`False`), Python даже не станет вычислять `B`, так как результат всего выражения уже очевиден.
{: .prompt-info }

## Приоритет операторов

Вот приоритет операторов по порядку в приоритете от наибольшего к наименьшему. Операторы одинакового приоритета располагаются на одинаковом уровне::

| Оператор | Описание |
| --- | --- |
| `(...)` | Круглые скобки (изменение порядка вычислений) |
| `**` | Возведение в степень |
| `*`, `/`, `//`, `%` | Умножение, деление, целочисленное деление, остаток |
| `+`, `-` | Сложение и вычитание |
| `<`, `<=`, `>`, `>=`, `==`, `!=` | Операторы сравнения |
| `not` | Логическое НЕ (Инверсия) |
| `and` | Логическое И (Логическое умножение) |
| `or` | Логическое ИЛИ (Логическое сложение) |

Поскольку операторы сравнения (`>`, `<`) имеют более высокий приоритет, чем логические (`and`, `or`), выражение:

```python
result = 5 > 3 and 10 < 20
```

Вычисляется именно так, как мы ожидаем: сначала проверяются сравнения, а затем применяется `and`. Однако для читаемости кода и предотвращения ошибок всегда рекомендуется использовать круглые скобки:

```python
result = (5 > 3) and (10 < 20)
```
