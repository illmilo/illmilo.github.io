Операторы условий позволяют использовать [логические выражения]({% post_url 2026-10-06-logicexpr %}) для управления ходом программы. Фактически, операторы условий расширяют функционал **логических выражений***, и практически всегда логические выражения вы будете использовать именно в **операторах условий**. Как именно это делать -- разберем в этом посте.

## Операторы условий

> **Операторы условий (ветвлений)** -- это операторы, управляющие *ходом программы* в зависимости от выполнения **условий** (логических выражений).
{: .prompt-info }

Операторы задаются такими словами и в **строго указанном порядке**:

* `if` -- если (от англ. `if`)
* `elif` -- иначе если (от англ. `else if`)
* `else` -- иначе (от англ. `else`)

> Условие всегда начинается с `if`. Нельзя прописать `elif` или `else` без `if`, ведь эти операторы содержат слово *иначе*, которое по определению отталкивается от первоначального условия. А вот не писать `elif` или `else` вполне себе возможно, это не ошибка.
>
> В программе может быть множество `elif`, ровно один `if` и ровно один `else`.
{: .prompt-info }

> В `else` никогда не пишется условие -- это частая ошибка новичков! "Иначе" по определению буквально является *любым другим случаем, кроме вышеизложенных* -- то есть, само по себе является условие, а поэтому в явном задании условия не нуждается.
{: .prompt-danger }

Синтаксис выглядит следующим образом:

```python
блок_до_ветвл
if лог_выраж1:
    блок1
elif лог_выраж2:
    блок2
else:
    блок3
блок_после_ветвл
```

> **Важные правила синтаксиса**:
> 
> 1. **Двоеточие (`:`)**: Каждое условие (`if`, `elif`, `else`) обязательно заканчивается двоеточием. Оно сообщает интерпретатору Python, что дальше начинается блок вложенного кода.
> 2. **Отступы**: В отличие от многих других языков программирования, где блоки кода выделяются фигурными скобками (`{}`), в Python **отступы обязательны**. Все строки кода, относящиеся к телу условного оператора, должны иметь одинаковый отступ (обычно 4 пробела). Без отступов Python выдаст ошибку `IndentationError`.
{: .prompt-warning }

Пример комплексного ветвления:

```python
score = 85

if score >= 90:
    print("Оценка: Отлично")
elif score >= 75:
    print("Оценка: Хорошо")
elif score >= 60:
    print("Оценка: Удовлетворительно")
else:
    print("Оценка: Неудовлетворительно")
```

Такая программа выведет:

```text
Оценка: Хорошо
```

Обратите внимание, что нам не приходится проверять верхнюю границу оценок, например: `90 < score <= 75`. Происходит это благодаря **альтернативным ветвлениям** `elif`. Структура `if -> elif -> else` является **одним деревом ветвлений**.

Если бы мы использовали `if`, то фактически сделали бы несвязные условия (деревья):

```python
score = 90

if score >= 90:
    print("Оценка: Отлично")
if score >= 75:
    print("Оценка: Хорошо")
if score >= 60:
    print("Оценка: Удовлетворительно")
else:
    print("Оценка: Неудовлетворительно")
```

В такой программе будет выводиться сразу 3 вывода:
```text
Оценка: Отлично
Оценка: Хорошо
Оценка: Удовлетворительно
```

Ведь все 3 условия: `>= 90, >= 75, >= 60` выполняются, и они разбиты, как независимые условия.

## Вложенные операторы `if`

Иногда требуется проверить дополнительное условие только тогда, когда первое условие уже оказалось истинным. Для этого используют вложенные `if`:

```python
x = 15

if x > 10:
    print("Число больше 10.")
    if x % 2 == 0:
        print("И оно четное.")
    else:
        print("Но оно нечетное.")
```

Обратите внимание, что глубина вложенности регулируется **увеличением отступов**. Хотя вложенность помогает решать сложные задачи, старайтесь не злоупотреблять ею (глубокий уровень вложенности ухудшает читаемость кода, превращая его в так называемую «пирамиду»).
